## Tipos basicos

| tipo | descripcioón | ejemplo
|----|----|----|
| number | número decimal | `123` |
| string | cadena de texto ASCII | `"Hola Mundo"` |
| boolean | valor boleando | `true`, `false` |
| tuple | colección de datos, inmutable | `1, 2, 3` |
| vector | colección de datos, mutable | `? 1, 2, 3` |
| map | colección de datos con relación clave-valor, mutable | `{key -> "value", [1] -> "number"}` |
| nil | valor vacio | `??` |
