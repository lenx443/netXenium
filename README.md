## netXenium

### ¿Qué es netXenium?

**netXenium es un lenguaje de scripting y un framework de red** diseñado para automatizar tareas, describir flujos de comunicación y controlar interfaces y dispositivos de transmisión de datos de forma directa, expresiva y multiplataforma.

Más que un simple lenguaje, netXenium es una **plataforma de control y orquestación de redes**, pensada para convertir comportamientos complejos en scripts claros, reproducibles y fáciles de razonar.

[Documentación](doc/)

---

### ¿Para qué se usa netXenium?

netXenium está orientado a escenarios donde la red no es un detalle secundario, sino el núcleo del problema:

* **Automatización de redes**

  * Configuración y control de interfaces
  * Ejecución de flujos personalizados
  * Scripts que reaccionan al estado y eventos de red

* **Análisis y experimentación**

  * Prototipado rápido de ideas
  * Pruebas de comportamiento
  * Inspección y manipulación de tráfico a alto nivel

* **Seguridad defensiva y ofensiva**

  * Auditorías controladas
  * Herramientas reproducibles
  * Análisis de vectores y superficies de ataque

* **Orquestación de sistemas**

  * Coordinación de múltiples dispositivos
  * Control centralizado de flujos de datos
  * Integración de distintos componentes sin glue code externo

En lugar de encadenar múltiples lenguajes y herramientas (Bash, Python, utilidades externas), **netXenium permite describir el flujo completo en un solo entorno**, diseñado específicamente para trabajar con redes.

---

### ¿Qué problema resuelve?

La mayoría de lenguajes de scripting y frameworks generalistas:

* Tratan la red como un recurso más
* Obligan a usar APIs genéricas y verbosas
* Fragmentan la lógica en múltiples capas
* Dificultan la representación clara de flujos complejos

netXenium invierte ese enfoque:

* La red es un elemento de primera clase
* Los flujos de datos se describen directamente
* El lenguaje se adapta al problema, no al revés

Esto da como resultado **scripts más cortos, más legibles y más expresivos**, especialmente cuando el objetivo no es programar una aplicación tradicional, sino **definir cómo fluye la información**.

---

### Capacidad y escalabilidad

netXenium está diseñado para crecer con el problema:

* Puede usarse para tareas simples de automatización
* Permite construir flujos complejos con múltiples estados
* Facilita la reutilización y composición de comportamientos

No es necesario cambiar de lenguaje ni de paradigma a medida que el sistema crece: **el mismo modelo sirve tanto para scripts pequeños como para sistemas más elaborados**.

---

### Multiplataforma y autonomía

netXenium está pensado para ejecutarse de forma consistente en distintos entornos, sin depender de stacks externos ni frameworks pesados.

Esto lo hace especialmente útil en:

* Sistemas Linux
* Entornos controlados o limitados
* Escenarios donde la portabilidad y el control son críticos

El comportamiento de los scripts se mantiene coherente independientemente del sistema, lo que facilita su uso en entornos heterogéneos.
